## 📌 Project Overview

The **Automobile Manufacturing & Sales Dashboard** is an interactive Power BI project designed to analyze vehicle sales, pricing trends, fuel types, mileage, engine capacity, and company performance. The dashboard transforms raw automobile sales data into meaningful business insights using Power BI visualizations, DAX measures, and Power Query.

---

## 🎯 Objectives

- Analyze automobile sales performance
- Compare company-wise selling prices
- Identify fuel type distribution
- Analyze mileage trends
- Compare engine capacities
- Study transmission-wise selling prices
- Build an interactive business dashboard

## 📌 Key Insights

- Toyota generated the highest selling price.
- Petrol vehicles account for the majority of total cars.
- Automatic transmission vehicles have a higher average selling price.
- Selling price generally decreases as mileage increases.
- Engine CC varies significantly across manufacturers.
